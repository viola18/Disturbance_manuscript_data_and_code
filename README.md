# Disturbance_manuscript_data_and_code

These are the datasets and code used in the "A National-Scale Framework for Predicting Risks of Water Quality Degradation from Combined Urban and Agricultural Disturbances" manuscript that's currently under review.

The no_missing_NLA_final.csv is the dataset used to build the structural equation model (SEM). 
The LAGOS_Disturbance_Final_SEM.RMD contains the R code used to build the SEM. 
The results and predictions from SEM were saved in the SEM_predictions_resid_sim.csv. 
The GBM_SHAP_Inlake_Predicting.RMD contains the R code used for gradient boosting machine modelling and generating Shapley Additive exPlanations (SHAP) plots.
